# 06 · 构建体系与依赖

## 1. 构建总览

项目使用 CMake(最低 3.22),C++20 标准,面向 Windows 平台(CI 同时验证 MinGW 与 MSVC)。顶层结构:

```
CMakeLists.txt          # 顶层:定义 VkNRC 可执行目标
├─ dep/CMakeLists.txt   # 第三方与自研库聚合(dep INTERFACE)
│   ├─ MyVK/            # 自研 Vulkan 封装 + 渲染图
│   ├─ glm/             # 数学库
│   ├─ half/            # fp16
│   ├─ spdlog/          # 日志
│   ├─ stb_image/       # 贴图加载
│   └─ tinyobjloader/   # OBJ 解析
├─ shader/CMakeLists.txt# glslc 编译着色器为数字数组头
└─ test/CMakeLists.txt  # 训练核测试(顶层默认不启用)
```

## 2. 顶层 CMakeLists 要点

```cmake
cmake_minimum_required(VERSION 3.22)
project(VkNRC)
set(CMAKE_CXX_STANDARD 20)          # C++20:span、concept、ranges、折叠表达式
set(CMAKE_CXX_VISIBILITY_PRESET hidden)  # Windows DLL 符号控制

# Windows 平台宏
add_definitions(-D_USE_MATH_DEFINES)     # M_PI 等数学常量
add_definitions(-DNOMINMAX)              # 避免 min/max 宏污染
add_definitions(-DWIN32_LEAN_AND_MEAN)   # 精简 Windows.h

# MinGW 静态链接运行时,便于分发
set(CMAKE_EXE_LINKER_FLAGS "-static-libgcc -static-libstdc++ -static")

# Release + 非 MinGW 开启 IPO(LTO),并检测编译器支持
if (CMAKE_BUILD_TYPE STREQUAL "Release" AND NOT MINGW)
    include(CheckIPOSupported)
    check_ipo_supported(RESULT IPO_SUPPORTED)
    ...
endif ()
```

目标:
```cmake
add_executable(VkNRC src/main.cpp src/Camera.cpp ... src/rg/*.cpp)
target_link_libraries(VkNRC PRIVATE dep shader)
```

> 注释要点:`src/Sobol.cpp`、`src/BlueNoise.cpp` 被注释掉(低差异序列采样器的历史实现,当前用 PCG);`add_subdirectory(test)` 也被注释(测试需要手动开启)。

## 3. dep 聚合库

```cmake
add_library(dep INTERFACE)
target_link_libraries(dep INTERFACE
        myvk::vulkan myvk::glfw myvk::rg myvk::imgui   # 自研
        glm stb_image tinyobjloader spdlog::spdlog half::half)
```

各子库通过 CMake ALIAS 目标暴露:`myvk::vulkan`、`myvk::rg`、`myvk::glfw`、`myvk::imgui`。

### 3.1 MyVK 内部目标

| 目标 | 内容 | 公开宏 |
| --- | --- | --- |
| `MyVK_Vulkan` | Vulkan 资源封装(40 个 .cpp) | — |
| `MyVK_RenderGraph` | 渲染图框架(接口 + 执行器) | `MYVK_ENABLE_RG` |
| `MyVK_GLFW` | GLFW 窗口/交换链扩展 | `MYVK_ENABLE_GLFW` |
| `MyVK_ImGui` | ImGui 集成 | `MYVK_ENABLE_IMGUI` |

可选 `MYVK_TESTING` 开启渲染图调试断言(`MYVK_RG_DEBUG`)。

MyVK 依赖 `dep/MyVK/dep/`:glfw、imgui、vma、volk、vulkan(Vulkan-Headers)。

## 4. 着色器构建(shader/CMakeLists.txt)

这是项目最有特色的构建环节:**着色器被编译成 C++ 数字数组头文件**,直接 `#include` 进源码,无需运行时文件读取:

```cmake
find_program(GLSLC "glslc" REQUIRED)   # 需要 shaderc 的 glslc

function(add_shader INPUT_FILE OUTPUT_FILE OPTION)
    add_custom_command(OUTPUT include/shader/${OUTPUT_FILE}
            COMMAND ${GLSLC} src/${INPUT_FILE} -o include/shader/${OUTPUT_FILE}
                    -mfmt=num --target-env=vulkan1.3 ${OPTION}
            DEPENDS src/${INPUT_FILE} ${SHADER_HEADER})
    add_custom_target(shader_${OUTPUT_FILE} ALL DEPENDS ...)
endfunction()
```

- `-mfmt=num`:输出 SPIR-V 的**十进制数字数组**,生成 `xxx.comp.u32` 头文件;
- `--target-env=vulkan1.3`:使用 Vulkan 1.3 目标环境(支持 1.3 特性与扩展语法);
- **依赖跟踪**:`SHADER_HEADER` 列表(所有公共 .glsl)作为 DEPENDS,公共头改动会自动触发所有依赖它的着色器重编;
- 同名着色器可用不同宏编译出多份:
  ```cmake
  add_shader(nrc_inference.comp nrc_inference_16.comp.u32 "-O;-DSUBGROUP_SIZE=16")
  add_shader(nrc_inference.comp nrc_inference_32.comp.u32 "-O;-DSUBGROUP_SIZE=32")
  ```
  C++ 侧 `NNInferenceShader::Create` 按设备实际 subgroup 大小(16/32)选择对应数组,并通过 `VkPipelineShaderStageRequiredSubgroupSizeCreateInfo` 固定执行子组尺寸。

全部编译产物:`vbuffer.vert/frag`、`path_tracer.comp`、`screen.vert/frag`、`nrc_indirect.comp`、`nrc_inference_{16,32}.comp`、`nrc_train_prepare.comp`、`nrc_gradient_{16,32}.comp`、`nrc_optimize{,_use}.comp`。

## 6. 硬件/驱动要求

- **必须**:支持 `VK_NV_cooperative_matrix` 的 NVIDIA GPU(驱动需启用该扩展);
- 其余必需扩展:`VK_KHR_swapchain`、`VK_KHR_deferred_host_operations`、`VK_KHR_acceleration_structure`、`VK_KHR_ray_query`、`VK_EXT_shader_atomic_float`;
- 特性:Vulkan 1.3 基础 + `bufferDeviceAddress`、`shaderFloat16`、`vulkanMemoryModel(DeviceScope)`、`computeFullSubgroups`、`subgroupSizeControl`、`storageBuffer16BitAccess`;
- subgroup 尺寸需为 16 或 32(编译了两份着色器,运行时不支持则报错退出);
- 本机演示需要 3 重帧缓冲与 swapchain 呈现。

## 7. 运行方式

```bash
# 构建(需要 glslc 在 PATH)
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j

# 运行:传入 OBJ 场景文件
./build/VkNRC scene.obj
```

启动后窗口内:
- **View 面板**:切换左/右半屏显示方法(None = 全路径追踪真值、NRC = 神经网络缓存、Cache = 仅缓存),勾选 Accumulate 查看时域累积;
- **NRC 面板**:Use EMA 切换 EMA 权重、Lock 冻结训练(可点 Train 1-Frame 手动训练一帧)、Re-Train 重置网络与优化器。

## 8. 测试目录(test/)

`test/` 内含独立的 NRC 训练核验证程序:

- `main.cpp` + `evaluate*.comp` / `train*.comp`:在 CPU 侧用 Eigen 实现同样的 MLP 前向/反向与 Adam,与 GPU 核输出逐位对比,验证 `NN_nv.glsl` 的正确性;
- `build_kernel.sh`:单独编译验证核;
- `mlp_learning_an_image/`:经典"MLP 拟合一张图"最小验证(编译 `gradient_32.spv` 等,确认反向传播正确);
- 依赖 `vuda/`(Vulkan 计算封装,测试专用)与 Eigen。

> 顶层 `CMakeLists.txt` 默认 `# add_subdirectory(test)`,即测试不随主工程构建;需要时取消注释并按 test/CMakeLists.txt 配置。
